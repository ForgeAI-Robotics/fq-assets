# 机场入口安检预览场景

版本 0.1.1，仅包含环境，不含旅客、机器人、行李和流程代码。

入口：`scene.usdc`（Isaac/USD）与 `scene.xml`（MuJoCo）。所有贴图为相对路径。环境包括排队通道、采样工位、检测仪外壳、等候标记、隔离座椅、班长桌和关闭状态的伸缩隔离带。

已启用 78 个静态碰撞体，涵盖地面、墙柱、桌面桌腿、检测仪外壳、隔离柱带、玻璃隔断和座椅。64 个装饰几何体（地砖线、等候标线、说明牌等）不参与碰撞。MuJoCo 与 Isaac Sim / PhysX 均通过地面、桌面、检测仪落球，隔离带和隔断阻挡，以及出口通行六项测试。证据见 `validation/airport_preview_v011.json`，复测脚本见 `tools/validate_airport_collision_*.py`。

所有物件目前固定在世界坐标中，随场景整体发布，尚未拆分为独立物件资产。隔离带是关闭状态的刚性薄盒代理，并非柔性带；垃圾桶、托盘及检测仪为实体简化外形，未实现空腔、插入口或交互关节。后续抓取、送检、开带需要单独建立可交互模型。

这是概念布局，不是虹桥机场实测 CAD。碰撞冒烟测试不代表接触参数标定或机器人操作验收。设备逻辑、放行控制及 Connection 接入尚未实现。网页预览器展示模型及碰撞结构，真实接触需在物理引擎中运行。
