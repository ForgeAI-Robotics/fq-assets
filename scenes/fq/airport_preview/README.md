# 机场入口批次防爆检测场景

版本 0.2.0。入口为 `scene.xml`（MuJoCo）和 `scene.usdc`（Isaac/USD），使用相对路径依赖。仅发布环境，不含人物、机器人、行李动画与业务流程程序。

## 布局

软带与隔离柱围合约 4.8 × 5.45 m 的检测等待区域。入口位于 Y=-1.8 m，出口位于 Y=3.65 m，前后开带口的柱中心间距均为 1.6 m，实际净宽受底座与带盒占用影响。外部排队通道接至入口。两侧及端部均用软带连接，替换上一版出口玻璃隔断和开放式工位布局。

区内左侧布置三个绿色旅客站位，右侧为检测桌、桌上探测仪、新拭子与弃纸桶。蓝色地面标记表示班长参考站位。中央留空用于逐人采样和往返送样；机器人型号未冻结，尚未完成整机运动包络验证。尺寸均为概念设计值。

## 预期流程与边界

入口放入一批旅客后关闭；旅客保持随身携包，不摘背包、不把包放到桌上。机器人依次对人员/衣物和随身包进行规定部位的痕迹采样，样本送到区内桌上探测仪，旅客留在围合区等待。所有应检结果有效阴性且无未解除异常后，由 Connection 授权、真人班长开出口带整批放行；报警则停止正常放行并复测/人工接管。

三人仅为演示批次，人体/衣物采样区域、人与包是否共用拭子及具体作业动作需按确认后的 SOP 实现。该文件描述流程意图，不代表流程、人物接触或检测逻辑已经实现。布局与流程意图另见 `layout.json`。

## 碰撞与验证

149 个环境几何体，其中 101 个启用静态碰撞。入口和出口默认均关闭，软带为固定刚性薄盒代理；尚无柔性带、开带控制器或锁扣操作。地面标记不参与碰撞。桌子、仪器、耗材和桶均固定在场景中，未拆为独立资产。

MuJoCo 通过 11 项测试：地面/桌面/仪器落球、入口/出口/两侧/端部软带阻挡、中央通道通行，以及测试中移除两条开口挡带后的贯通检查。Isaac/PhysX 通过 9 项落球和围合边界阻挡测试。证据为 `validation/airport_preview_v020.json`，复测脚本为 `tools/validate_airport_collision_mujoco.py` 和 `tools/validate_airport_collision_isaac.py`。历史 v010/v011 报告对应旧版布局。

这些测试不代表真实软带力学、人员安全、机器人操作、探测仪判读或完整业务验收。
