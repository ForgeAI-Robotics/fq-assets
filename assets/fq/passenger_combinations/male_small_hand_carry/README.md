# 男性旅客 + 手提小包

Human: third_party:characters/rocketbox_male_adult_01 (Microsoft MIT). Bag: third_party:bags/gso_digital_camo_double_decker_lunch_bag (Google CC-BY-4.0). Both source licenses are included.

assembly.usdc preserves UsdSkel bones and attaches the bag to Bip01 R Hand. Frames 0–60 are a small pose-following example, not a walking motion. preview.xml is a static skinned view. Custom ribbons/handle fit the pose visually; no cloth, gripping force, walking controller or detailed contact validation. The bag is kinematic in the assembly; the standalone source bag retains its own rigid physics.
