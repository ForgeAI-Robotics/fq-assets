# 材质与纹理

网页一级导航仅有物体、场景。材质/纹理、机器人、末端执行器属于物体的子类；运行时按能力区分，不进入普通物体采样池。

首批墙面、普通地面、地毯、木纹、石材复用 office_baseline 的原始贴图，不移动路径或修改基准场景。floor.png 是备用；当前地面使用 carpet_photo_v1.png。材质各自版本 0.1.0；库最新 release 仍为 v0.1.0，新条目来自 main。

三个 photo_v1 贴图来自参考照片生成，方法与假设保存在 scene 的 photo_materials.json。wall.png、floor.png 原始生成方法未记录，不补造来源。铺贴尺寸为估计或未知；没有法线/粗糙度贴图，没有实测接触参数。浏览器球面/平面预览采用近似光照。

SIMPLE 的显式 materials 配置可覆盖已登记的场景表面 slot；不传配置则完全保持基准外观。视觉替换不改变几何、质量或摩擦。按实例名称独立的 RNG 不受材质采样影响。记录材质 ID、版本、SHA256、repeat；依赖整个快照锁定。当前支持 MuJoCo；Isaac/USD 显式拒绝带材质覆盖的配置，避免静默显示错误外观。

机器人与末端执行器仅预留分类，此阶段未导入模型。SIMPLE 原生资产将在后续逐项确认来源、格式及兼容性后迁移。
