# 橙色大杯奶茶杯

根据用户提供的《橙色奶茶杯.mp4》制作。杯身贴图取自第 90、120、195 帧的可见表面，按锥度校正并融合。杯盖贴图取自第 285 帧。侧面接缝、反光、杯盖浮雕均为近似。封闭杯盖，无吸管。固定杯盖不可拆卸。

model.glb 为内嵌贴图的预览模型，Y 向上。model.xml 与同目录 OBJ、PNG 构成 MuJoCo 资产，Z 向上，单位米，物体原点在杯底中心。MJCF 自带自由关节，无桌面。碰撞使用独立凸包，适用于外部接触。

用户实测带盖高 172 mm、不带盖高 160 mm、顶部外径 100 mm、底部外径 60 mm。将顶部外径用于带盖模型的最大外径。空杯带盖质量估设为 30 g，惯量、质心及摩擦为仿真初值。未模拟液体、杯壁挤压和杯盖脱落。抓取实验仍需校准质量和接触参数。
