# 冰椰水瓶（抹茶冰椰）

参考用户提供的转台短视频。几何为参数化重建，正背面标签取自 2.25 秒和 0.20 秒附近的可见画面。侧面过渡、瓶肩、瓶盖纹路和透明度为近似。随包只包含裁自瓶身的标签，包装图案权利归其权利人。

| 属性 | 数值 | 来源 |
| --- | --- | --- |
| 含盖总高 | 291 mm | 实测 |
| 瓶盖外径 | 40 mm | 实测 |
| 瓶底外径 | 52 mm | 实测 |
| 瓶身最大外宽 × 深 | 58.3 × 55.3 mm | 依据视频估计 |
| 空瓶带盖质量 | 28 g | 估计 |
| 质心距瓶底 | 139 mm | 估计 |

模型原点位于瓶底中心。MuJoCo 和 USD 使用米及 Z-up，GLB 使用米及 Y-up，贴图内嵌。瓶体和盖子组成一个刚体，设有独立的瓶体和瓶盖凸碰撞体。盖子固定闭合。摩擦、惯量和质量为仿真初值。透明外观使用基础 alpha 材质。

- `model.xml` 为可直接加载的 MuJoCo 模型，包含自由关节。生成场景时，将瓶底原点置于支撑平面上方少量距离。
- `model.usda` 为 Z-up USD 资产，加载时保留同目录贴图，引用默认 prim `/IcedCoconutWaterBottle`。
- `model.glb` 为便携预览模型。
- `validation.json` 记录几何核验和立放、侧放落至平面的物理测试。抓取、投放、变形和真实摩擦尚未校准。
